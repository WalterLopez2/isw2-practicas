\# GitFlow vs. Trunk-Based



GitFlow utiliza varias ramas para organizar el desarrollo.



Incluye ramas como `main`, `develop` y `feature`.



Las funcionalidades se desarrollan en ramas separadas.



Es útil para proyectos con versiones planificadas.



Sin embargo, puede requerir más coordinación entre ramas.



Trunk-Based integra cambios frecuentemente en una rama principal.



Sus ramas de trabajo suelen ser pequeñas y de corta duración.



Esto facilita detectar conflictos y recibir retroalimentación rápida.



Es adecuado para equipos que practican integración continua.



Para una aplicación web elegiría Trunk-Based.



Permite entregar mejoras frecuentes y simplifica la integración.



Los feature flags permiten activar o desactivar funciones mediante configuración.



Así se pueden integrar cambios sin exponer funciones incompletas.



Los equipos deben revisar los cambios antes de integrarlos para mantener la calidad del código.
