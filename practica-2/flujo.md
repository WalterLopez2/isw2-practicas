\# GitFlow vs. Trunk-Based



GitFlow utiliza varias ramas para organizar el desarrollo.

Incluye ramas como main, develop y feature.

Las funcionalidades se desarrollan en ramas separadas.

Es util para proyectos con versiones planificadas.

Sin embargo, puede requerir mas coordinacion entre ramas.

Trunk-Based integra cambios frecuentemente en una rama principal.

Sus ramas de trabajo suelen ser pequeñas y de corta duracion.

Esto facilita detectar conflictos y recibir retroalimentacion rapida.

Es adecuado para equipos que practican integración continua.

Para una aplicacion web elegiria Trunk-Based.

Permite entregar mejoras frecuentes y simplifica la integracion.

Los feature flags permiten activar o desactivar funciones mediante configuracion.

Asi se pueden integrar cambios sin exponer funciones incompletas.


Los equipos deben revisar los cambios antes de integrarlos para mantener la calidad del codigo.
